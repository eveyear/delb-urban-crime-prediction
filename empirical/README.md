# Empirical Research Pipeline

This directory contains the complete, reproducible empirical workflow for the
crime-predictability and bicycle-mobility manuscript. Raw source files remain
read-only under `data/raw/`; every derived artifact is stored here with an
immutable run identifier.

## Reproducibility rules

1. Never edit or overwrite raw source data.
2. Use `crime_type_unified` as the authoritative harmonized crime category.
3. Preserve valid runs and useful intermediate/non-publication results. When a
   reviewed error is isolated, patch only affected records or partitions and
   delete the validated erroneous or interrupted artifacts.
4. Fit discretization thresholds and predictive-model parameters on training
   data only.
5. Store the command, configuration snapshot, package environment, input-file
   manifest, logs, tables, figures, and interpretation for every experiment.
6. Copy only selected final assets into `paper_assets`; do not delete the
   corresponding full run directory.

## Experiment sequence

- E00: input inventory and data-quality audit
- E01: standardized event data and station reconciliation
- E02: spatial-temporal panel and descriptive analysis
- E03: numerical validation of the discrete entropy lower bound
- E04: city-level information-theoretic experiment
- E05: local spatial information-value experiment
- E06: matched predictive-model experiment
- E07: theory-practice gap and efficiency analysis
- E08: crime-type heterogeneity
- E09: robustness analysis (accepted run `20260719_183554_E09_robustness`)
- E10: placebo analysis (accepted run `20260719_190015_E10_placebo_null`)
- E11: synthesis and manuscript integration

## Running E02

Open the project in PyCharm and select `E02 Spatial Temporal Panel`, or run:

```bash

  --paths empirical/config/paths.yaml \
  --cities empirical/config/cities.yaml \
  --e02 empirical/config/e02.yaml
```

The E02 command assigns crime and eligible bicycle endpoints to deterministic
projected 1 km grids, fixes the analysis domain using training-period crime
locations, creates every city-grid-day combination, and adds calendar and
strict lag-1 fields. City checkpoints make the run resumable.

```bash

  "$(cat empirical/runs/latest_e02_run.txt)"
```

`processed_data/e02/latest_e02_data.txt`.

## Running E03

Open the project in PyCharm and select `E03 Discrete Bound Validation`, or
run:

```bash
MPLCONFIGDIR=/private/tmp/entropy-matplotlib \
PYTHONPATH=empirical/src \
/opt/anaconda3/bin/python3 empirical/run_e03_bound_validation.py \
  --config empirical/config/e03.yaml
```

E03 evaluates the centered discrete-Gaussian partition function, the exact
integer maximum-entropy envelope and its generalized inverse, the conservative
closed-form lattice bound, maximum-entropy inequalities, and Monte Carlo
recovery. It also uses unconditional E02 count entropies only as a numerical
range stress test; conditional entropy and bicycle information are first
estimated in E04.

All E03 manuscript-ready PNG/PDF figures are generated by the Python
`matplotlib` code in the experiment. The Excel workbook is a QC artifact and
is not an article-figure source. The accepted run is recorded in
`runs/latest_e03_run.txt`.

The QC workbook can be regenerated after the numerical run with:

```bash
node \
  empirical/src/reporting/build_e03_workbook.mjs \
  "$(cat empirical/runs/latest_e03_run.txt)"
```

## Running E04

Open the project in PyCharm and select `E04 City Information`, or run:

```bash
MPLCONFIGDIR=/private/tmp/entropy-matplotlib \
PYTHONPATH=empirical/src \
/opt/anaconda3/bin/python3 empirical/run_e04_city_information.py \
  --config empirical/config/e04.yaml
```

E04 estimates baseline and bicycle-aware conditional crime-count entropy for
three cities, two spatial domains, and pooled/annual periods. The primary
estimator is Miller--Madow; strict lag-1 bicycle states use training-only
positive-flow tertiles. Each specification has 1,000 deterministic-seed,
7-day block-bootstrap replicates. Raw conditional mutual information is
retained, while only the theoretical-bound input is projected to be
nonnegative.

All E04 PNG/PDF article figures are generated by the versioned Python
`matplotlib` code. The QC workbook contains formula-linked summaries and
aggregated uncertainty diagnostics; the complete 24,000 bootstrap rows remain
in CSV and Zstandard Parquet files in the accepted run directory. The accepted
run is recorded in `runs/latest_e04_run.txt`.

Regenerate the audit workbook without rerunning the experiment with:

```bash
node \
  empirical/src/reporting/build_e04_workbook.mjs \
  "$(cat empirical/runs/latest_e04_run.txt)"
```

## Running E06

Open the project in PyCharm and select `E06 Matched Predictive Models`, or run:

```bash
MPLCONFIGDIR=/private/tmp/entropy-matplotlib \
PYTHONPATH=empirical/src \
/opt/anaconda3/bin/python3 empirical/run_e06_predictive_models.py \
  --config empirical/config/e06.yaml
```

E06 fits four paired count-prediction families for each city: a smoothed
empirical state mean, Poisson fixed-effects regression, negative-binomial
fixed-effects regression, and Poisson histogram gradient boosting. Within
each family, the baseline and bicycle-aware members differ only by the frozen
E04 lagged bicycle-flow state. Hyperparameters are selected using the
2020--2021 training and January--June 2022 validation periods; final models
are evaluated once on July--December 2022. A lag-7 seasonal naive forecast is
retained as an explicitly nonmatched external benchmark.

Every fitted specification has its own serialized model, tuning record, and
test-prediction checkpoint. Completed specifications are reused on resume.
The accepted run contains all row-level predictions, local metrics, and 1,000
paired 7-day block-bootstrap replicates per city--model comparison. All E06
PNG/PDF article figures are generated by the versioned Python `matplotlib`
code. The accepted run is recorded in `runs/latest_e06_run.txt`.

Regenerate the audit workbook without rerunning any model with:

```bash
node \
  empirical/src/reporting/build_e06_workbook.mjs \
  "$(cat empirical/runs/latest_e06_run.txt)"
```

## Running E07

Open the project in PyCharm and select `E07 Theory-Practice Gap`, or run:

```bash
MPLCONFIGDIR=/private/tmp/entropy-matplotlib \
PYTHONPATH=empirical/src \
/opt/anaconda3/bin/python3 empirical/run_e07_theory_practice.py \
  --config empirical/config/e07.yaml
```

E07 re-estimates the city-level exact DELB on the same July--December 2022
test observations used by E06. It does not subtract the pooled 2020--2022 E04
bound from a test-period MSE. The same deterministic nonoverlapping 7-day
blocks jointly resample conditional entropy and both members of every matched
prediction pair. The resulting tables report the predictability gap
(`MSE - DELB`), information-use efficiency (`DELB / MSE`), theoretical bound
reduction, empirical MSE improvement, and gap narrowing
(`delta MSE - delta DELB`).

For the local analysis, exact grid-level DELB reductions are re-estimated from
training plus validation observations ending 30 June 2022. They are then
joined to the untouched E06 test-period local MSE improvements. E07 reports
city--model Spearman associations with 2,000 paired-grid bootstrap resamples,
Benjamini--Hochberg adjustment across the 12 local tests, city-fixed-effect
HC3 regressions, and median-based four-category maps. The accepted E05
eligibility set is retained without outcome-based revision.

All seven E07 PNG/PDF article-figure groups are generated by versioned Python
`matplotlib` code. The complete 12,000-row joint bootstrap remains in
Zstandard Parquet; the Excel workbook is a QC artifact. The accepted run is
recorded in `runs/latest_e07_run.txt`.

## Running E08

Open the project in PyCharm and select `E08 Crime Type Heterogeneity`, or run:

```bash
MPLCONFIGDIR=/private/tmp/entropy-matplotlib \
PYTHONPATH=empirical/src \
/opt/anaconda3/bin/python3 empirical/run_e08_crime_type_heterogeneity.py \
  --config empirical/config/e08.yaml
```

E08 keeps `PROPERTY_THEFT`, `VEHICLE_THEFT`, and `BURGLARY` exactly as
recorded in the authoritative `crime_type_unified` field. Each category has
its own strict lag-1 target count, conditional-entropy states, exact DELBs,
validation tuning, serialized models, and held-out integer predictions. The
E04 training-only bicycle thresholds and the prespecified 1 km training
bicycle-covered domain remain frozen.

Theory is estimated both for pooled 2020--2022 observations and for the
July--December 2022 test window. One thousand shared 7-day block resamples
align the three crime categories within each city and period. Prediction uses
the same four matched model families as E06, independently tuned for every
city, category, and information set. Category heterogeneity is evaluated with
paired block-bootstrap differences and Benjamini--Hochberg adjustment.

All eight E08 PNG/PDF article-figure groups are generated by the versioned
Python `matplotlib` code. The accepted run retains 18,000 theory-bootstrap
rows, 36,000 prediction-bootstrap rows, 2,051,784 row-level predictions, and
72 serialized matched models. The Excel workbook is a QC artifact. The
accepted run is recorded in `runs/latest_e08_run.txt`.
