# Applied Sciences submission and Overleaf compilation

Upload the contents of the lightweight V2 archive to a new Overleaf project,
select `template.tex` as the main document, and use pdfLaTeX. The project keeps
the MDPI class files in `Definitions/`, the manuscript sections in `sections/`,
and the accepted Python-generated figures in `figures/`.

Key files:

- `template.tex`: English submission manuscript and project entry point.
- `supplement.tex`: independent English empirical Supplementary Materials.
- `sections/theoretical_framework.tex`: the four-part core theory: general
  integer prediction, exact DELB, attainability/two-slack decomposition, and
  CMI ordering under added side information.
- `sections/theoretical_proofs.tex`: Appendix A with Fano, closed-form,
  temporal, stationary, vector, and application extensions plus all proofs.
- `sections/generated/s7/`: S7 tables and numerical macros synthesized from
  accepted E12--E15 outputs.
- `figures/s7/`: hash-verified figures generated by the E12--E15 Python
  programs.
- `Definitions/`: MDPI class and journal definitions required for compilation.
- `empirical/run_problem_chain_figure.py`: Python source for the new unified
  RQ1--RQ3 evidence-chain figure in `figures/problem_chain/`.
- `template_Chinese.tex`: synchronized Chinese comparison manuscript.
- `supplement_Chinese.tex`: synchronized Chinese Supplementary Materials.
- `empirical/run_e17_estimator_domain_sensitivity.py`: estimator-specific
  city randomization calibration with both nine-test and global 27-test
  adjustment, plus training-period-frozen analysis-domain sensitivity.
- `out/template.pdf`: locally validated 45-page English manuscript.
- `out/template_Chinese.pdf`: locally validated 35-page Chinese manuscript.
- `out/supplement.pdf` and `out/supplement_Chinese.pdf`: locally validated
  nine-page independent supplements.

Before journal submission, replace author, affiliation, correspondence,
repository, author-contribution, funding, and declaration placeholders.
Empirical numbers in the
manuscript are synthesized from accepted experiment tables rather than entered
manually. The archived Version 1 project is not modified.

For the independent Supplement, switch the Overleaf main document to
`supplement.tex`. The Chinese comparison files are for author-side checking
and are not part of the English submission package.
